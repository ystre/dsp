== About this book

This book is the design and the operating manual of {project}, a network server
built for the highest throughput per core and the lowest tail latency the Linux
kernel allows, TCP first, with UDP and WebSocket designed in.

Phase 1 (this version) delivers the framework: the design, the contracts every
implementation must honour, a CI pipeline that runs anywhere, the benchmarking
framework, the Helm charts and the ETSI SOL004 package. The server and the load
generator exist as minimal "hello world" programs that exercise all of it.
Phase 2 implements the design (<<roadmap>>).

Chapters marked *Contract* define names, formats and semantics that are fixed
across implementations; tools, dashboards and tests depend on them.
